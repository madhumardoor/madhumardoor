### 🏢 [AI Office Demand Intelligence Platform](https://github.com/madhumardoor/ai-office-intelligence)

Production-grade **agentic RAG** system that identifies companies likely to need more office space — combining structured company/hiring data, coworking tenant data, geospatial queries, and live news into a single grounded, cited answer.

- 🧭 **Query router** — decides per-question whether to hit PostgreSQL, PostGIS, pgvector, web search, or a combination
- 🗄️ **Hybrid retrieval** — semantic + keyword + metadata + spatial filtering, reranked before reaching the LLM
- 📊 **Transparent signal engine** — separates **FACT → SIGNAL → INFERENCE**, every claim cited, no invented sources
- 🛠️ **Tool-calling agent** — read-only, parameterized tools only (no raw SQL access, no injection surface)
- 🗺️ **PostGIS spatial search** — "companies within 5km of Whitefield" as a real geospatial query
- 📈 **RAG evaluation harness** — precision/recall, faithfulness, hallucination rate, latency, cost per query

`FastAPI` `LangChain` `LangGraph` `pgvector` `PostGIS` `PostgreSQL` `Streamlit` `Docker` `n8n`
